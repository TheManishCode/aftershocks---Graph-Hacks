## Built on

Aftershock is built on top of the **Epicenter** and **Tessera** codebases, and stands on:

- [FalkorDB](https://falkordb.com): the property graph every answer is read from
- [tree-sitter](https://tree-sitter.github.io) and [tree-sitter-language-pack](https://github.com/Goldziher/tree-sitter-language-pack): parsing for every language
- [Model Context Protocol](https://modelcontextprotocol.io): the agent interface
- [QuixBugs](https://github.com/jkoppel/QuixBugs): 40 real bugs used in the testlab
- [click](https://github.com/pallets/click), [httpx](https://github.com/encode/httpx), [zustand](https://github.com/pmndrs/zustand), [flask](https://github.com/pallets/flask) and [starlette](https://github.com/encode/starlette): the benchmark repos

Thanks to [WeMakeDevs](https://www.wemakedevs.org) and FalkorDB for running **Graph Hacks**, where this started.
