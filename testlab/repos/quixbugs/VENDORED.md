# QuixBugs (vendored)

Source: https://github.com/jkoppel/QuixBugs at `4257f44b0ff1181dedaedee6a447e133219fcebf`, MIT (see LICENSE and upstream `legal_notes.txt`).
Paper: Lin, Koppel, Chen, Solar-Lezama, *QuixBugs: a multi-lingual program repair benchmark set based on the Quixey Challenge*, SPLASH 2017.

Changes: the correct programs became the package `quixbugs`; tests import it instead of switching on `--correct`; a per-test 5s alarm was added because buggy versions can loop forever. The buggy versions live in `testlab/bugs/quixbugs/`.

Generated by `scripts/vendor_quixbugs.py` (40 programs).
